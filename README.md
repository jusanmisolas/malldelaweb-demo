# MALLDE Law

Extract the ZIP and commit its contents to the root of your GitHub repository. Keep `index.html` and `.nojekyll` at the root, alongside the asset files and folders.

In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, then choose **main** and **/ (root)**. Save and open the Pages URL when GitHub finishes publishing.

The site is static and requires no build command. Links are relative so the files work under a repository URL or at the root of a custom domain.

The consultation form opens a prepared request in the visitor's email app. Direct submission requires a separate form or email service.
